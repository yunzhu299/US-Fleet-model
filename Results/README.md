# Manuscript results

This folder contains the compact, publication-facing products generated by
`Scripts/03-Figures/Run_All_Main_Text_Figures.R`.

- `Data`: figure-ready CSV source data, named to match Figures 2–17.
- `Figures`: final main-text PNG files, named to match Figures 2–17.

The full model outputs and intermediate recycling-analysis tables remain in
`Outputs`. Rerunning the main-text figure runner refreshes both folders here.
